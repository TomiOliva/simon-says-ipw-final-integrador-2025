## 📝 Descripción
Implementación del clásico juego Simon Says utilizando HTML5, CSS3 y JavaScript (ES5).

El juego consiste en memorizar y reproducir secuencias de colores que van aumentando en dificultad.

## 🚀 Tecnologías
- HTML5
- CSS3 (Flexbox)
- JavaScript ES5
